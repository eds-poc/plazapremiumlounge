# Side Nav: authoring guide

The account pages' side navigation (the live site's sidebar on Update Profile, Update Password and
My Booking): a list of links beside the page's content. The link to the page being shown is the
active one.

## Table: one link per row

| Side Nav |
| --- |
| [Update Profile](/en-uk/membership/update-profile) |
| [Update Password](/en-uk/membership/update-password) |
| [My Booking](/en-uk/membership/my-booking) |

- **One link per row** (a bulleted list of links in one cell works too). Use the page's path, e.g.
  `/en-uk/membership/update-profile`, in each language's own pages.
- **Active link**: the one whose path is the page's address (with or without `.html` or a trailing
  `/`), shown in the heavier weight and announced as the current page.
- Only web and site links are kept.

## Where

In the section with the page's main content (e.g. before the Profile Form block): from 576px the section
is two columns, the links a quarter of the width beside the rest of its content; on phones the links
sit above it as full-width grey tabs, the active one maroon.
