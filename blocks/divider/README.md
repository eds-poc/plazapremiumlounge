# Divider: authoring guide

A thin horizontal line between parts of a page, as the live Eligible Lounges page draws between its
lists. Add it wherever a line is needed; delete the table to remove the line.

## Table: the block name only

| Divider |
| --- |
|  |

- The table needs no content: anything typed in it is ignored.
- Put it where the line should be, e.g. at the start of a section, before its heading, or between
  two paragraphs.
- Don't use a horizontal rule (`---`) for this: in Document Authoring that starts a new section and
  isn't shown on the page.

## Look

A light grey 1px line across the content width, with 28px above and below, the same as the live
site. Nothing about it is authorable.
